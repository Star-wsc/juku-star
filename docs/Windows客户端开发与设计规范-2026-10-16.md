# 短剧库 Windows 桌面端开发与设计规范（完整版）

**版本**：v1.0 · 2026-10-16  
**定位**：类 macOS 风格的 Windows 桌面客户端，连接现有 `juku` 后端（1.0+2.0 复刻）  
**原则**：**视觉风格是硬约束**——圆润、连续、不割裂；控件交互符合直觉（开关在右侧）

---

## 0. 目标与非目标

### 目标

- 现代化圆润 UI，接近 Mac 桌面观感  
- 功能对齐 Android 1.3.8 / 后端能力：剧库、播放、设置、下载等  
- 本机可打包为 Windows 安装包 / 绿色 exe  
- 可复用现有 `/api/ui/*`，不重写业务后端  

### 非目标

- 不追求 100% 像素级仿 macOS  
- 不在本阶段做上架微软商店  
- 不在此文档里重写后端（见《项目开发与交接文档》）  

---

## 1. 技术选型（推荐）

| 方案 | 推荐度 | 说明 |
|------|--------|------|
| **Tauri 2 + 前端（React/Vue/纯 HTML）** | ★★★★★ | 包体小、性能好、好做圆角/毛玻璃 |
| **Electron + 前端** | ★★★★ | 生态熟、好调；体积偏大 |
| Flutter Desktop | ★★★ | UI 顺滑；打包与插件略费劲 |
| WinUI 3 / WPF | ★★ | 原生但圆角/毛玻璃成本高 |

**本规范默认按：Tauri（或 Electron）+ 自绘前端 UI。**  
业务层直接 HTTP 调后端，播放用 **系统 WebView / mpv / 原生 video**（见 §5）。

## 2. 设计系统（必须遵守）

### 2.1 视觉 DNA

1. **圆润优先**：禁用尖角大色块；窗口、卡片、输入框、按钮一律圆角  
2. **连续不割裂**：避免「一块一块硬拼」；侧栏与内容用浅色阶过渡，不粗黑框分割  
3. **大留白**：列表呼吸感，字重层次清晰  
4. **轻阴影**：卡片阴影柔和（不脏、不重）  
5. **三色内**：一套中性 + 一个强调色，不彩虹堆砌  

### 2.2 色板（默认浅色，必须一致）

| Token | 值 | 用途 |
|-------|-----|------|
| `--bg` | `#F5F5F7` | 窗口底 / 桌面衬底 |
| `--surface` | `#FFFFFF` | 卡片、主内容 |
| `--sidebar` | `#ECECF1` → `#E4E4EA` | 侧栏渐变 |
| `--text` | `#1D1D1F` | 主文字 |
| `--text-secondary` | `#6E6E73` | 辅助文字 |
| `--text-tertiary` | `#8E8E93` | 占位符 |
| `--fill` | `#ECECF1` | 输入框/未选 Chip |
| `--accent` | `#4D9FFF` | 主强调（蓝） |
| `--accent-2` | `#6C5CE7` | 渐变辅助（紫） |
| `--accent-grad` | `linear-gradient(135deg,#4D9FFF,#6C5CE7)` | 选中/主按钮 |
| `--danger` | `#FF3B30` | 错误 |
| `--success` | `#28C840` | 成功 |
| `--shadow-card` | `0 8px 24px rgba(0,0,0,0.08)` | 卡片 |
| `--shadow-soft` | `0 2px 8px rgba(0,0,0,0.06)` | 小控件 |

**深色模式（P1）：**  
`--bg #1C1C1E`，`--surface #2C2C2E`，`--text #F5F5F7`，强调色不变。

### 2.3 圆角与尺寸

| 组件 | 圆角 | 备注 |
|------|------|------|
| 主窗口 | **16–18px** | 标题栏与内容一体 |
| 海报卡片 | **14–16px** | 图文一体圆角 |
| 输入框 / 搜索 | **12–18px** | 胶囊搜索条优先 |
| 按钮（主） | **12px** 或胶囊 | 高 36–40 |
| Chip / 筛选 | **胶囊 999px** | 高 30–32 |
| 弹窗 | **16px** | 无硬直角 |
| 侧栏选中 | **10–12px** | 胶囊背景 |

### 2.4 字体

- 中文优先：`PingFang SC` / `Microsoft YaHei`  
- 数字英文：`SF Pro Display` / `Segoe UI Variable`  
- 字阶（示例）：

| 级别 | 字号 | 字重 |
|------|------|------|
| 页面标题 | 28 | 700 |
| 区块标题 | 17–20 | 600 |
| 正文 | 14 | 400/500 |
| 辅助 | 12 | 400 |
| 标签 | 11 | 500 |

### 2.5 布局节奏

- 侧栏宽 **176–200px**  
- 内容区 padding **24–32px**  
- 卡片间距 **16–20px**  
- 海报比例 **3:4**，高度约 **168–228px** 宽 **168px**（网格）

## 3. 交互规范（必须遵守）

### 3.1 开关 Switch——**一律靠右**

```text
┌─────────────────────────────────────────┐
│  文字标题                        [开关] │  ← 标题左，开关右
│  说明文字，一行或两行                    │
└─────────────────────────────────────────┘
```

| 规则 | 说明 |
|------|------|
| **位置** | 行右侧，右边距 16px；**禁止放左侧** |
| 点击区** | 整行可点，不只是开关 |
| 开 | 强调色填充（`--accent`） |
| 关 | 灰填充 `#ECECF1` |
| 尺寸 | 约 51×31（类 iOS）或 44×24 |
| 圆角 | 全圆角 |

### 3.2 其它控件

| 控件 | 规则 |
|------|------|
| Chip 筛选 | 选中：accent 填充白字；未选：fill 底深色字 |
| 主按钮 | accent 渐变或实色，圆角，禁用降透明度 |
| 次按钮 | 白底 + 细边或 fill 底 |
| 列表行 | 圆角卡片或连续行；hover 轻填充 |
| 弹窗 | 圆角 16、遮罩 `rgba(0,0,0,0.35)`、内容 padding 24 |
| 滚动条 | 细、圆、半透明，不抢眼 |

### 3.3 反馈

- 操作后 ≤100ms 视觉反馈  
- 加载用圆角 Progress / 轻量骨架屏  
- 错误：圆角 SnackBar / Toast，不用生硬系统弹窗风格

## 4. 页面结构（对照效果图）

### 4.1 主窗框

```text
┌─ 圆角 18px ─────────────────────────────────┐
│ ● ● ●     标题「短剧库」              搜索  │  毛玻璃标题栏
├──────────┬──────────────────────────────────┤
│ 侧栏     │  筛选 Chip 行                    │
│ 剧库*    │  ┌────┐ ┌────┐ ┌────┐          │
│ 追剧     │  │海报│ │海报│ │海报│          │
│ 下载     │  │标题│ │标题│ │标题│          │
│ 历史     │  └────┘ └────┘ └────┘          │
│ 设置     │                                  │
│          │                                  │
│ 服务器   │                                  │
└──────────┴──────────────────────────────────┘
```

- 选中侧栏项：圆角浅 accent 底 + 左侧 4px accent 条（可选）  
- **不要**粗竖线生硬分割侧栏  

### 4.2 剧库

- 标题 + 副文案「共 N 部」  
- 搜索：右侧圆角胶囊  
- Chip：站源、分类、**排序（含「随机」）**、VIP  
- 网格海报；下拉/按钮刷新：**只刷快照，不拉源站**  
- 更新剧库：设置里；更新中 **开关/按钮禁用**  

### 4.3 播放页（P1）

- 圆角内容区；控制条半透明圆角  
- 大号圆角按钮；进度条圆头  
- 返回不跳变（布局连续）  

### 4.4 设置页

- 分区卡片，圆角 16  
- 行：**文字左、开关右**  
- 关于：版本号动态读 `version`  
- 红果版不得出现其他站源名

## 5. 播放器选型

| 方案 | 场景 |
|------|------|
| 系统 WebView + 后端播放页 | 最快出活 |
| **mpv / libmpv 嵌入** | 播放稳定、格式全，推荐桌面 |
| 原生 video（Electron/Tauri） | 中等复杂度 |

**建议：** 第一期 WebView 先跑通；第二期换 mpv 提升体验。  
对接后端：`hls/open` 得到 URL；心跳 60–90s；progress `sequence` 递增。

## 6. 架构（前后端分离）

```text
Windows App (Tauri/Electron)
  ├─ UI 前端（本规范的 Mac 风）
  ├─ 客户端存储（服务器地址、排序、主题）
  └─ HTTP → 后端 /api/ui/*
                ↓
         红果/黄果/黄豆 取流
```

### 6.1 与后端契约（摘要）

- Cookie + `X-Juku-Viewer` + `Sec-Fetch-Site: none`  
- `GET /api/ui/viewer` 身份  
- `dramas`：`refresh=1` 会触发源站拉取（设置里用）  
- 播放：`open` → `hls/open`（失败再 `plan`）→ `control/heartbeat` → `progress`  
- 图片：`/api/ui/image?url=`  

详见《项目开发与交接文档》《API速查表》。

### 6.2 桌面端建议模块

```text
src/
  ui/
    theme/tokens.css      # 色板、圆角、阴影（唯一来源）
    layout/AppShell.tsx   # 圆角窗、侧栏、标题栏
    components/           # Card, Chip, SwitchRow, Modal…
    screens/              # Library, Detail, Player, Settings…
  core/
    api.ts                # 统一请求、鉴权头
    session.ts
  tauri/ 或 electron/     # 壳、菜单、窗口圆角
```

## 9. 开发注意（关键）

1. **风格**：圆角、连续、留白；不要做「Win95 分组框」  
2. **开关一律右侧**；整行可点  
3. **色板写死在 tokens**，禁止页面随意色值  
4. **刷新语义**：界面刷新 ≠ 服务端拉源站  
5. **红果版** UI 无其他站源名  
6. **版本号**改一处（打包配置）并同步设置页  
7. **密钥/密码**不进前端仓库；默认账号只放安装说明  
8. 播放退出记得 close 会话、存进度  
9. 中文 UTF-8，避免文件乱码  
10. 大列表虚拟滚动，海报懒加载

## 10. 推荐实施顺序

```text
① Tauri/Electron 壳：圆角窗、标题栏三灯
② tokens.css + AppShell + 侧栏
③ 剧库假数据网格（先看观感）
④ 接后端 viewer + dramas
⑤ 详情 + 播放
⑥ 设置（开关右侧）+ 版本号
⑦ 打包 exe/msi
⑧ 对齐 Android 排序/随机/刷新语义
```

**每步截图对比效果图**，风格不对立刻改，不要后补。
