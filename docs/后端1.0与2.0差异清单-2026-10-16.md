# 短剧库 后端 1.0 vs 2.0 差异清单

> 来源：服务器 `juku-v2.bak-20261016`（2.0 二进制）与 `~/juku/internal`（1.0 源码）符号/路由/配置对比。  
> 日期：2026-10-16。用于二次开发/重制时对齐能力。

## 一、能力矩阵

| 能力 | 1.0 源码 | 2.0 二进制 | 重制建议 |
|------|----------|------------|----------|
| 播放 plan 决策 `POST /api/ui/playback/plan` | 无 | 有 | 必补 |
| 搜索联想 `GET /api/ui/search/suggestions` | 无 | 有 | 必补 |
| 兼容提示字段（解码/容器） | 部分（客户端侧有） | 服务端下发 | 必补 |
| **优先原始 MP4 / HLS**（`originalPlaybackEnabled`） | 无 | 有 | 必补 |
| **按站源直连** `directSources` | 无 | 有 | 必补 |
| 条件式 302 直连 / redirect | 无 | 有 | 必补 |
| 内置 hls.js 原始 HLS | 无 | 有 | 必补 |
| `compatible_original` 播放模式 | 无 | 有 | 必补 |
| 播放会话保活/恢复、预取 | 有（较简） | 更完整（activity/history run） | 对齐 |
| 分离音视频 remux / merge 计划 | 无 | 有 | 必补 |
| Emby **自动同步**（海报/通知扫描） | 无 | 有 | 建议补 |
| Emby 合并版 STRM / cover API | 部分 | 更全（cover、merged.mp4） | 建议补 |
| 账号导入 `account/import`、guest import | 无/弱 | 有 | 建议补 |
| 按站源分类下载 `groupBySource` | 无 | 有 | 建议补 |
| 后台播放 `backgroundPlayback` | 无 | 有 | 可选 |
| 管理端 playback/emby 设置 API | 无 | 有 | 必补 |
| 红果 App 预加载取流 | 无（旧 video_model） | 无（旧二进制也是旧口） | **已修，保留** |
| 红果网页 play-info + 网页密钥 | 无 | 无 | **已修，保留** |

说明：2.0 二进制（10-07）**也还没有** duanju 10-15 的预加载取流；红果修复比「官方 2.0」更新。

## 二、2.0 独有 API（1.0 源码中不存在）

```
POST /api/ui/playback/plan
GET  /api/ui/search/suggestions
POST /api/ui/account/import
POST /api/ui/admin/emby
POST /api/ui/admin/emby/sync
POST /api/ui/admin/playback
GET/POST /api/ui/playback/media/*     （原始媒体网关）
GET  /api/emby/cover
GET  /api/emby/merged.mp4
GET  /api/emby/segment.ts
POST /api/ui/merge/cancel             （1.0 可能无 cancel）
```

```json
  "directSources": ["hongguo"],

download.groupBySource

```

`JUKU_ADMIN_USER/PASSWORD`、`JUKU_OUTPUT_DIR`、`JUKU_FFMPEG`、`JUKU_PROXY_URL`、  
`JUKU_HONGGUO_URL`、`JUKU_HUANGDOU_URL`、`JUKU_HUANGGUO_*`、  
`JUKU_AES_KEY_HEX`、`JUKU_PARAM_KEY/IV`、`JUKU_API_BASE`、`JUKU_TOKEN`、  
`JUKU_CDN_URL`、`JUKU_INTERFACE_KEY`、`JUKU_PICKER_START_DIRECTORY`

## 五、1.0 保留且不必删

- 剧库/搜索/榜单/推荐/追剧/历史/下载/合并/Emby 导出  
- 心跳、进度、预取、弹幕（红果）  
- 三站源 provider 骨架（黄果/黄豆/红果）  
- FFmpeg 转码/换封装链路  

## 六、重制优先级建议

**P0（播放能用、对齐 2.0）**
1. 红果取流（已修：preload + play-info + 网页密钥）  
2. `playback/plan` + 原始 MP4/HLS + `directSources` + 302 直连  
3. `search/suggestions` + 兼容提示  

**P1（体验）**  
4. Emby 自动同步/海报  
5. 合并/下载按站源分目录  
6. 账号导入与更细权限  

**P2**  
7. 后台播放、播放资源限额、缓存策略  

## 七、与客户端约定（勿破坏）

- `X-Juku-Viewer`、Cookie、`Sec-Fetch-Site: none`  
- 心跳 60–90s、progress `sequence` 单调递增  
- `hls/open` 优先；失败再 `playback/plan`（客户端已有兼容层）  
- `run` 为数值类型
