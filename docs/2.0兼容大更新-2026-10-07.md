# JukuApp 2.0 兼容大更新 · 2026-10-07

## 结论：脱敏包不是“优化版”

对 `JukuApp-源码-脱敏.zip` 与工作区 `JukuApp` 做了逐文件 MD5 对比：

| 项 | 结果 |
|----|------|
| Kotlin 源码 49 个文件 | **完全一致** |
| README / gradle / mock-server | **完全一致** |
| 差异 | 仅脱敏包去掉 `juku-release.jks` / `keystore.properties` / `local.properties`，补了 `keystore.properties.example` |

**不需要替换源码。** 真正的大更新是按 `juku2.0/index.html` 做 1.0 / 2.0 双兼容。

## 本次改动

### P0 播放 plan 兼容
- 新增 `data/remote/PlaybackCompat.kt`
- `hls/open` 失败（无 url / 报错）时自动调 `POST api/ui/playback/plan` 再试一次
- 1.0 无 plan 接口时忽略失败，行为与原来一致
- `PlaybackRepositoryImpl` 与 `DownloadWorker` 共用该兼容层

### P1 搜索联想
- `GET api/ui/search/suggestions`
- 防抖 250ms，结果以 SuggestionChip 展示，点击触发搜索
- 1.0 / 失败静默降级，不影响手动搜索

### P1 兼容提示
- 解析 `videoCodecUnsupported` / `audioCodecUnsupported` / `containerCompatibility` / `needDanmakuGuideType`
- 播放页 Snackbar 提示一次，不阻断播放

### mock-server
- 补 `search/suggestions`、`playback/plan`，便于本地自测 2.0 行为
