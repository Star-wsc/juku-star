## 4. 与后端契约（必须对齐 Android）

### 4.1 身份与 Cookie

| 项 | 规则 |
|----|------|
| Cookie | `HTTPCookieStorage.shared` 接受任意名（动态 SHA-256 名） |
| 身份头 | 每个需鉴权请求带 `X-Juku-Viewer: <viewer.id>` |
| 浏览器指纹 | `Sec-Fetch-Site: none` |
| 首次 | `GET /api/ui/viewer`（无 confirm 建 Cookie）→ `?confirm=1` 拿完整 viewer |

### 4.2 播放

```text
POST /api/ui/playback/open     → session, episodes, initialIndex
POST /api/ui/playback/hls/open → url（服务端 m3u8 或原始地址）
  失败再 POST /api/ui/playback/plan
POST /api/ui/playback/control  → heartbeat（60–90s）
POST /api/ui/playback/progress → sequence 单调递增
```

- `run` 为数值（Int/UInt64），勿当字符串  
- `episode` 可能是 String 或 Int，宽松解析  
- 图片一律 `/api/ui/image?url=`

### 4.3 2.0 可选（失败静默）

- `GET /api/ui/search/suggestions`  
- `playback/plan` 的 `mode` / 兼容提示字段  
- 「优先原始」时 url 可能是 **http mp4 / m3u8 直链**（注意 ATS）

### 4.4 ATS（Info.plist）

开发期允许 HTTP（局域网服务器）：

```xml
<key>NSAppTransportSecurity</key>
<dict>
  <key>NSAllowsArbitraryLoads</key>
  <true/>
</dict>
```

上架前应改成按域名例外。

## 5. 功能拆解（按页面）

### 5.1 Auth / 服务器

- 输入 IP:端口（保留用户输入的 `https://`）  
- 测试连通：`GET /api/ui/viewer`  
- 登录 / 注册 / 匿名进入  
- 密码不 trim、不滤字符  

### 5.2 Library 剧库

对齐 Android 1.3.8：

- 站源筛选、分类、排序（**默认「随机」**）  
- 排序：最新上线 / 名称 / 上线日期 / 播放量 / **随机**  
- 下拉刷新 = **只刷快照**，不触发服务端拉源站  
- 设置里「更新剧库」= `GET /api/ui/dramas?refresh=1`，更新中禁用按钮  
- 列表用 LazyVGrid；封面 `AsyncImage` + 渐变占位  

### 5.3 Detail 详情

- 海报、标题、简介、分集列表  
- 播放入口、下载入口（P1）  
- 追剧按钮  

### 5.4 Player 播放（核心）

`PlaybackController` + `AVPlayer`：

| 能力 | 说明 |
|------|------|
| 起播 | `hls/open` → AVPlayer URL |
| 心跳 | 60–90s `control/heartbeat` |
| 进度 | 5–15s `progress`，sequence++ |
| 切集 | 复用 session；可 `prepare` 下一集 |
| 退出 | `control/close` + 持久化进度 |
| 后台 | 记录进度；可选画中画 |

**注意：** 服务端出的是转码后 HLS/MP4，一般可直接 AVPlayer 播；若开「原始直链」且是 HTTP，需 ATS。

### 5.5 Settings

- 服务器地址、账号、主题、默认倍速  
- 版本号用 `CFBundleShortVersionString`  
- 红果版文案 **不得出现其他站源名**

## 6. 开发流程（建议按此顺序）

```text
① 工程能被 xcodegen 生成并通过 xcodebuild
② APIClient：viewer / 登录 / dramas
③ Library 列表能显示

⑩ 再补搜索、追史、下载
```

**每完成一步就推一次仓库**，让 Actions 先告诉你编译过不过。

## 7. GitHub Actions 出 IPA（无 Mac）

### 7.1 仓库布局

```text
juku/          # 或单独 ios 仓库
└── ios/
    ├── project.yml
    └── JukuApp/...
```

### 7.2 推荐 workflow（无证书 → 可重签 IPA）

目标：**不配 p12**，产出未签名/伪签名 IPA，用户重签。

```yaml
name: iOS Build IPA
on:
  workflow_dispatch:
  push:
    paths:
      - 'ios/**'

jobs:
  ipa:
    runs-on: macos-14
    timeout-minutes: 45
    steps:
      - uses: actions/checkout@v4

      - uses: maxim-lobanov/setup-xcode@v1
        with:
          xcode-version: '15.4'

      - name: Install xcodegen
        run: brew install xcodegen

      - name: Generate project
        working-directory: ios
        run: xcodegen generate

      - name: Build unsigned
        working-directory: ios
        run: |
          xcodebuild \
            -project JukuApp.xcodeproj \
            -scheme JukuApp \
            -configuration Release \
            -destination 'generic/platform=iOS' \
            -archivePath build/Juku.xcarchive \
            CODE_SIGN_IDENTITY="" \
            CODE_SIGNING_REQUIRED=NO \
            CODE_SIGNING_ALLOWED=NO \
            archive

      - name: Package IPA
        working-directory: ios
        run: |
          APP=$(find build/Juku.xcarchive -name '*.app' | head -1)
          mkdir -p Payload
          cp -R "$APP" Payload/
          zip -qr Juku.ipa Payload
          rm -rf Payload

      - uses: actions/upload-artifact@v4
        with:
          name: Juku-ipa
          path: ios/Juku.ipa
```

**要点：**

- `workflow_dispatch`：手动点一次出包，省 macOS 时长  
- 关闭签名，避免证书 Secrets  
- 产物在 Actions → Artifacts → `Juku-ipa`  

### 7.3 若要用自有证书（可选）

Secrets：`APPLE_CERTIFICATE_P12`、`APPLE_CERTIFICATE_PASSWORD`、`APPLE_TEAM_ID`  
产物为 development 签名 IPA，用户仍可再重签。  
免费 Apple ID 约 **7 天** 有效。

### 7.4 省 Actions 时长

- 只在 `ios/**` 变更或手动时构建  
- 可加：PR 只 `xcodebuild build` 不打包

## 9. iOS 实现要点（踩坑）

### 网络

- Cookie：不要手写 Cookie 名，用 `HTTPCookieStorage`  
- 所有 API 请求统一走 `APIClient`，集中加 `X-Juku-Viewer`  
- 密码、URL 勿擅自 trim  

### 播放

- 优先 `AVPlayer` + HLS；失败再提示  
- 退出页面前 `close` 会话并保存进度  
- 断网恢复后可提示「重试」而非闪退  

### UI

- 对齐 Android 1.3.8：排序默认「随机」、下拉只刷快照  
- 封面渐变占位，无图显示「暂无封面」  
- 设置页简洁；红果版不出现其他站源名  

### 与 Android 对齐清单（可打勾）

- [ ] 服务器可改、可测连通  
- [ ] 登录/匿名  
- [ ] 剧库筛选 + 排序（含随机）  
- [ ] 下拉刷新不拉源站  
- [ ] 详情播放  
- [ ] 心跳/进度/续播  
- [ ] 设置页版本号正确  
- [ ] 红果版无「黄果/黄豆」字样

## 10. 常见问题

| 问题 | 处理 |
|------|------|
| Actions 找不到 scheme | `xcodegen generate` 后看 `JukuApp.xcodeproj` 是否生成；scheme 名 `JukuApp` |
| 签名报错 | 先用上面 **无签名** 参数；有证书再改 Manual |
| 装不上 | 未信任证书 / 免费签过期 / 重复 BundleId 冲突 |
| 播不了 | 查后端 `app.log`；看是否 `hls/open` 失败；ATS 是否拦 HTTP |
| 乱码中文 | 文件存 UTF-8；Avoid 源文件用系统默认 GBK 编辑 |
| macOS 超时 | 降 Xcode 版本固定、减资源、只手动出包 |
