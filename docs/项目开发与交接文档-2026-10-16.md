## 3. 架构（后端）

```text
Android/iOS/Web
    │  Cookie + X-Juku-Viewer + Sec-Fetch-Site: none
    ▼
UI API  /api/ui/*
    │
    ├─ 剧库/搜索/榜单/推荐/追剧/历史
    ├─ 播放会话 open → hls/open | plan | stream → 心跳/进度/预取
    ├─ 下载任务 → FFmpeg 合并
    └─ Emby 导出/同步
    │
    ▼
Provider 层
    ├─ hongguo  → App API (fqnovel) / 网页 play-info / 备用 djapi
    ├─ huangguo → 访客会话 + HLS
    └─ huangdou → API + 试看限制
```

### 红果取流（已修复，2026-10-16）

**顺序：**

1. **主路径** `POST /novel/player/multi_video_model/preload/v1/`  
   - body：`mixed_video_id_map: {"1004":[vid]}`, `dr_scene: "preload"`  
   - 跳过 `bytevc2`，选 `bytevc1`/H.264  
   - 旧 `video_model/v1/` 现返回**空包**，勿再依赖  
2. **网页** `POST https://hongguoduanju.com/api/video/protected/play-info`  
   - `{series_id, item_id, definition}`，头：Referer=player 页、Origin、`X-Xs-From-Web: 1`  
   - 支持 `play_info` DASH 分离音视频 + `legacy_play_info`  
   - 密钥 `player_access_key`：tag `22`/`webdevice` 用 **+delta** 解包；`11`/`appdevice` 用 **-delta**  
3. **备用** `https://djapi.999888456.xyz/api/hongguo/play`（加密响应，常无 key_urls）

**FFmpeg：** 分离音视频时双 `-i`，`-decryption_key` 挂在**每个**输入前。

**已验证：** 《113的便宜羊》第 4–8 集、《一个人的长征》1–5 集 `playback.mode` 成功。

## 12. 数据来源与站源策略（重制必读）

**内容不自建**：剧集元数据与视频地址全部来自第三方源站接口/网页，本项目只做聚合、缓存、转码、分发。

| 站源 ID | 主机/入口 | 取流方式 | 限制 |
|---------|-----------|----------|------|
| `hongguo` | `hongguoduanju.com`、`api5-normal-sinfonlineb.fqnovel.com`、`djapi.999888456.xyz` | App preload + 网页 play-info + 备用 | 未登录网页仅前约 3 集；App 需签名 |
| `huangguo` | `huangguo.video` / `huangguoai.com` / cloudfront | 访客会话 + HLS | 封面 AES 解密 |
| `huangdou` | 可配置 baseURL | 站方 API | 多为试看，勿当正片 |

### 设计原则

1. **每个站源一个 Provider**（`provider_<source>_*.go`），实现统一接口：列表/详情/搜索/取流  
2. **业务层只认** `Drama` / `Chapter` / `providerMedia`，不感知源站细节  
3. **源站挂了只下线该源**，不影响其它源  
4. **可插拔**：加新源 = 新增 provider 文件夹/文件 + 注册 source id  
5. **本地缓存** `library.json` 只是缓存，不是版权内容库；下载文件在 `-out` 目录  

### 源站变更应对

- 取流失败优先看 `data/logs/app.log`（`playback.failed` / `provider.*`）  
- 红果签名、密钥算法见第 13 节；源站改版只改 `provider_hongguo_*`  
- 代理：`network.proxy` / `JUKU_PROXY_URL`，应用层请求走代理，FFmpeg 内部回环勿走外部代理

## 13. 关键技术细节（换目录后仍需要）

### 13.1 红果 App 请求签名（X-Gorgon / X-Khronos）

- 主机：`https://api5-normal-sinfonlineb.fqnovel.com`  
- UA：`com.phoenix.read/73532 (Linux; U; Android 16; ...)`  
- 公共 query：`aid=8662&app_name=novelread&version_code=73532&device_platform=android&...`  
- 签名算法在 `provider_hongguo_sign.go`（MD5 query/body + 自定义混淆 → hex `X-Gorgon`）  
- 设备 `device_id` / `iid`：数字 ID，存在 `library.json` → `hongguoApp`  

### 13.2 红果预加载取流（2026-10 起主路径）

```http
POST /novel/player/multi_video_model/preload/v1/
Content-Type: application/json
# + X-Gorgon / X-Khronos / X-SS-STUB

{
  "mixed_video_id_map": { "1004": ["<vid>"] },
  "dr_scene": "preload",
  "biz_param": {
    "detail_page_version": 0, "device_level": 3,
    "need_all_video_definition": true, "video_platform": 1024,
    ...
  }
}
```

- 响应：`data.<vid>.video_model` → `video_list[]`  
- **跳过 `codec_type == bytevc2`**，优先 `bytevc1` / h264  
- 加密轨：`encrypt_info.spade_a` → `hongguoContentKey()`  
- **旧口 `/novel/player/video_model/v1/` 已空包，禁止依赖**  

### 13.3 红果网页 play-info（备用）

```http
POST https://hongguoduanju.com/api/video/protected/play-info
Content-Type: application/json
Referer: https://hongguoduanju.com/player/{series_id}/{item_id}
Origin: https://hongguoduanju.com
X-Xs-From-Web: 1

{"series_id":"...","item_id":"...","definition":"720p"}
```

- `play_info`：DASH 分离音视频（`main_url` + `audio.main_url`）  
- `legacy_play_info`：整段兼容流  
- 403 = 未登录/会员，非代码 bug  

### 13.4 媒体密钥 `player_access_key` / `spade_a`（CENC）

`hongguoContentKey`（`provider_hongguo_playback.go`）：

1. base64 解开 → `tagLength = (raw[0]^raw[1]^raw[2]) - 48`  
2. tag 在尾部，seed = 两字节异或  
3. **方向按 tag**：`22` / `webdevice` → `decoded = prev^cur + (21+popcount(i))`  
   `11` / `appdevice` → 减去同一 delta（App 方向）  
4. 解出 32 位 hex AES-128 key  
5. **音视频分离时，FFmpeg `-decryption_key` 必须挂在每个 `-i` 之前**  

### 13.5 播放链路（后端 → 客户端）

```text
open 播放会话
  → resolvePlaybackMedia (Provider)
  → 可选 plan / 画质
  → hls/open 返回 /api/ui/playback/hls/index.m3u8 或 stream fMP4
  → FFmpeg 转码/换封装，或 302 直连（2.0）
客户端：HlsMediaSource / ProgressiveMediaSource
心跳 60–90s，progress sequence 单调递增
```

### 13.6 客户端契约（Android/iOS 必须保持）

| 项 | 值 |
|----|-----|
| 身份 | `X-Juku-Viewer` + 服务端动态 Cookie |
| 浏览器指纹 | `Sec-Fetch-Site: none` |
| 取流 | `hls/open` 优先；失败再 `playback/plan` |
| 字段 | `run` 数值；episode 可 str/int |
| 图片 | `/api/ui/image?url=` |
| 心跳 | 60–90s；会话闲置 10 分钟释放 |
